# Timezy — Logo Exploration Brief

## Brief

- **Working name:** Timezy
- **Product:** personal, offline-first task planning for Android and iOS
- **Audience:** people organizing work, study, and personal tasks from a phone
- **Brand cues:** calm, friendly, clear, light, dependable
- **Product promise:** make today's next task easy to see and act on
- **Visual context:** warm cream / pale green UI, dark green primary, soft rounded surfaces
- **Logo constraints:** recognizable at app-icon scale, single-colour first, simple silhouette; no shadow or gradient inside the mark

## Word map

Today · rhythm · small steps · focus · calm · completion · time made easier

This map was distilled from the PRD and UI spec with Graphify's semantic extraction: personal planning → dated tasks → completion/progress, supported offline on Android and iOS.

## Category guardrails

Avoid a stock calendar page with date number, clock hands, a generic check inside a circle, and a generic ascending analytics chart. Productivity/collaboration marks in the reference set often use blue or multicolour abstract shapes, containment, and rounded-square geometry; the exploration starts in monochrome and favors a distinct silhouette.

## Three concepts

1. **Time Anchor — letterform:** a custom T with a small stepped terminal, linking the working name to the next action of the day. Risk: a T can feel generic if the offset foot is too subtle.
2. **Dayfold — pictorial:** a quiet page-fold silhouette for a day being arranged, without a date number or checklist. Risk: the page metaphor is familiar in productivity software.
3. **Quiet Steps — abstract:** one rising, three-step path for manageable tasks and daily progress. Risk: it could be mistaken for a data chart unless the rhythm reads clearly.

## Working recommendation

Start with **Quiet Steps**: it expresses a steady, low-pressure rhythm without drawing a clock, checkbox, or calendar. Keep **Time Anchor** as the strongest name-led alternative. These are explorations, not cleared trademarks or final logo assets.

## Selected direction

**Quiet Steps (concept C) selected** for the MVP. The production vector uses the UI's dark green (`#064B20`) and is available at `assets/quiet-steps.svg`; Android uses a matching adaptive launcher icon. The mark should remain one-color and shadow-free. This is a working project identity, not trademark clearance.
